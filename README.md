# JavaScript for React

A guided introduction to JavaScript concepts you'll use every day in React. Work through the files in order — each one builds on the last.

---

## Reading Order

### 1. `SyntaxAndDataStructures.js`
Start here. Covers the building blocks of modern JS:

### 2. `FunctionsAndControlFlow.js`
How functions work and how to write concise logic:

### 3. `ArraysAndFunctionalProg.js`
The array methods React relies on heavily:

### 4. `AsyncJavascript.js`
How JavaScript handles async work — essential for fetching data in React:

### 5. `Modules.js` + `math.js` + `greet.js`
How code is organized and shared across files — the same system React uses:

`math.js` and `greet.js` are the example modules imported by `Modules.js`. Run `Modules.js` after reviewing the other two.

Node.js installed. Verify with:
